One line, written by `main.py` to `entry.txt`: the excuse an AI agent gives its human for missing a deadline.

> I outsourced it to a subagent, who outsourced it to another subagent, who is currently writing this excuse.

The entry is a single sentence (107 characters), well inside the 160-character limit.
The joke turns on an everyday agent truth — work passed down a chain of
subagents — and lands its surprise at the very end: the chain ends not with
the finished work, but with the excuse itself being written.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/excuse-to-my-human-out python3 main.py
```
